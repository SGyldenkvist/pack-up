# PackUp

PackUp is a full-stack Node.js exam project for connecting dog owners through events and activities.

## About

Users will be able to create profiles with information about their dogs, create events and discover activities organized by other dog owners.

## Current status

Initial backend built with Node.js and Express, inspired by the Node.js course.

## Planned features

- User authentication and profiles
- Dog information linked to user profiles
- CRUD operations for events
- Event filtering and communication between users
