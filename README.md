# PackUp

PackUp is a full-stack Node.js exam project for connecting dog owners through events/activities.

## About

Users will be able to create profiles with information about their dogs, create events and discover activities organized by other dog owners.

## Current status

Initial project structure created with Node.js and Express. Basic routes have been implemented, while the remaining functionality is planned for future development.

## Planned features

- User authentication and profiles
- Dog information linked to user profiles
- CRUD operations for events
- Event filtering and communication between users
